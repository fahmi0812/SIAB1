# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Security Advisories:
<https://github.com/fahmi0812/SIAB1/security/advisories/new>

Do not open a public issue, pull request, or discussion for a security problem.

Include the affected component, steps to reproduce, and the expected impact.
Do not include real student, teacher, or exam data, or live credentials, in the report.

## Scope

Application code, deployment configuration, and the Android kiosk client in this repository.
Testing against any live deployment requires written permission from the maintainer.
